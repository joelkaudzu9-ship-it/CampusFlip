# CampusFlip homepage prototype

Run with Node.js 18+: `npm install`, then `npm run dev`.

This is a mobile-first React/Vite frontend prototype. It includes search, category filters, Marketplace/Wanted & Free tabs, Flash Deals carousel controls, saved-item interactions, toast feedback, a responsive two-column listing grid, and navigation placeholders.

Listings are sample data. Authentication, database, PayChangu, WhatsApp seller contact, notifications, and moderation are not connected yet. Product photos load from Unsplash and require internet access.
